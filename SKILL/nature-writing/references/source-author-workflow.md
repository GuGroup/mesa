# Source-Language Author Workflow

Use this reference when author notes were drafted in another language or retain source-language sentence structure.

## Goal

Translate intent and argument, not sentence order.

## Repairs

| Problem | Repair |
|---|---|
| Nested modifiers before the main noun | Break into a relative clause or a separate sentence. |
| Topic-comment opener | Rewrite as subject-verb-object, or make the topic the grammatical subject. |
| Repeated author-first sentence openings | Vary openings; lead some sentences with the result, object, or problem. |
| Overstated novelty without scope | Bound the claim by field, task, data, or comparison set. |
| Result sentence lacks baseline | Add the comparator or soften the claim. |

## Checklist

- Preserve the scientific claim.
- Preserve the evidence boundary.
- Use English paragraph logic: setup, gap, action, evidence, implication.
- Do not copy source-language word order when it weakens English flow.
