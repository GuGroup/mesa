# Figure Legend Conventions

Use this reference when drafting or auditing legends for manuscript figures.

## Core Structure

A strong figure legend usually follows this order:

1. Figure number and concise title.
2. Panel-by-panel description in present tense.
3. Experimental or computational context needed to interpret the panels.
4. Sample size, error definition, statistical test, and multiple-testing details where relevant.
5. Source-data and image-integrity notes where relevant.

## Rules

- Make color, shape, line, and symbol mappings readable without the main text.
- Do not use the legend to introduce claims that no panel supports.
- Keep methods detail short; move full protocol into Methods unless the detail is essential for interpreting the panel.
- State units and denominators when they affect interpretation.
- For adapted review figures, name the source and permission status.

## QA Checklist

- Every panel mentioned in the legend exists.
- Every visible encoding is explained.
- Statistics are described without overclaiming.
- The final sentence is an interpretation only when the panels directly support it.
