# Citation Source Schema

`citation_sources.json` is a controlled source library, not a citation-placement
decision file.

## Top-Level Keys

```json
{
  "schema_version": 2,
  "project": "mos_0629_2",
  "created_at": "2026-07-06T00:00:00+09:00",
  "extraction_policy": {
    "additive_search": false,
    "source_scope": "local primary PDFs and explicit reference lists only"
  },
  "primary_papers": [],
  "second_neighbor_references": [],
  "warnings": []
}
```

## Primary Paper Record

```json
{
  "paper_id": "P001",
  "citation_key": "Wang2015",
  "title": "Transition-Metal Doped Edge Sites in Vertically Aligned MoS2 Catalysts for Enhanced Hydrogen Evolution",
  "authors": ["H. Wang", "C. Tsai"],
  "year": "2015",
  "doi": "10.1007/s12274-014-0677-7",
  "pdf_path": "project/.../papers/strategy/wang2015-2.pdf",
  "collection": "strategy",
  "source_role": "primary_project_pdf",
  "abstract_excerpt": "...",
  "reference_count": 42,
  "supports": [],
  "warnings": []
}
```

`supports` is intentionally empty in this skill. Claim-level support matching
should be generated by a later citation-selection layer after manuscript prose
exists.

## Second-Neighbor Reference Record

```json
{
  "reference_id": "R001",
  "citation_key": "Norskov2004",
  "title": "Trends in the Exchange Current for Hydrogen Evolution",
  "authors": [],
  "year": "2004",
  "doi": "10.xxxx/example",
  "raw_reference": "Full reference string as printed in a primary PDF.",
  "cited_by": ["P001"],
  "source_pdf_paths": ["project/.../wang2015-2.pdf"],
  "source_reference_numbers": [
    {
      "cited_by": "P001",
      "reference_number": "12"
    }
  ],
  "citation_contexts": [
    {
      "cited_by": "P001",
      "source_citation_key": "Wang2015",
      "reference_number": "12",
      "citation_marker": "[12]",
      "sentence": "Sentence from the primary paper body where reference [12] was cited."
    }
  ],
  "source_role": "second_neighbor_reference",
  "supports": [],
  "warnings": []
}
```

Second-neighbor references are deduplicated by DOI when a DOI is present, then
by normalized raw reference text when no DOI is present.

`citation_contexts` is evidence for later citation selection. It is not a
guarantee that the second-neighbor reference supports every sentence in the
new manuscript.
