# Manuscript Writing

Write from the supplied research context and the actual calculation outputs,
tables, figures, and notes. Use the Introduction, Methods, Results and
Discussion, title and abstract, and Supporting Information writing skills as
needed. Standalone figure skills can render available data for the manuscript.

Describe the methods used, distinguish results from interpretation, and state
limitations and incomplete work. Cite the sources used and include a
References section. Use the DOCX insertion and formatting skills when needed.
