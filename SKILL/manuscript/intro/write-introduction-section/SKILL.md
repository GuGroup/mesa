# Write the Introduction

Use the user's research question, supplied background, and available references.
Introduce the reaction or materials problem, explain the specific question or
gap, and state what the present calculations investigate. Cite the sources used
for prior findings and identify their relationship to the present study. Make
clear which questions the study addresses and which remain open.

Write the Introduction directly in the manuscript or in a separate Markdown
section when requested.
