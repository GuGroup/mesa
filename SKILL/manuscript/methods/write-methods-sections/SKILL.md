# Write the Methods

Read the available calculation settings, input structures, logs, and analysis
notes. Describe the models and the methods that were used. Include enough
detail to interpret the calculations, such as the backend and model or
functional, boundary conditions, convergence settings, and analysis conventions,
when recorded and relevant. Mention defaults only where the tool or a run output
establishes that they applied.

Explain relevant energy references or corrections using the definitions applied
in the analysis. See [the formalism guide](references/methods_formalism_guide.md)
for writing examples. Mark essential unavailable details clearly. Write the
Methods directly in the manuscript or as a separate Markdown section.
