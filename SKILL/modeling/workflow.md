# Modeling

Choose the modeling skill that matches the requested structure. Use
`import-bulk-structure` to import or validate a bulk source,
`build-slab-models` to generate surfaces, and `build-gas-phase-models` for
isolated gas references. Use the appropriate adsorbate placement skill when
a surface and adsorbate are available.

Use the actual source files and supplied crystallographic settings. Preserve
source identifiers, site metadata, and validation outputs. Report unresolved
structure ambiguity or missing inputs. Put generated structures and their
metadata in the requested output directory.
