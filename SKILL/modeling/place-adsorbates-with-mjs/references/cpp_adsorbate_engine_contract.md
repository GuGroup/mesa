### `-a` vs `--precursor-radius` (contract-critical)

Current binary: `-a` = contact-anchor radius, `--alpha-factor` = construction factor,
`--precursor-radius` = deprecated alias of `-a`. The reference `engine_command.txt` passes
**both** `-a 1.0` and `--precursor-radius 1.52`; under current semantics these collide, so that
command reflects the **legacy** binary (`-a` = alpha, `--precursor-radius` = radius). The skill
therefore keeps two separate knobs — `--engine-alpha` (→ `-a`) and `-a/--adsorbate-radius`
(→ `--precursor-radius`) — and must not conflate them.

## Determinism

Geometry is deterministic (CGAL/qhull/Voro++); **no RNG seed**. Same staged POSCAR + same flags
+ same binary ⇒ identical graph. (High-symmetry inputs can hit a degenerate-image code path — out
of scope here; pre-jittering or the fixed binary handle it.)

## stdout / stderr / exit

- **stdout**: human-readable progress (`Parsing POSCAR…`, `Weighted atoms: N`, mode, warnings).
  Not machine payload — do not parse as data.
- **stderr**: warnings/errors.
- **exit code**: `0` on success (main tail returns 0); `1` on any argument, file-parse, PBC, or
  construction error (multiple `return 1` sites in the parser and pipeline).

## Generated artifacts (written to CWD)

Always: `weighted_alpha_graph.json` (**the payload**), `weighted_alpha_graph.txt`,
`weighted_alpha_stats.txt`, and OBJ meshes (`weighted_alpha_no_duplication.obj`,
`weighted_alpha_voro_corrected*.obj`, hierarchy `*_p1/p2/p3_level.obj`, `*_full_hierarchy.obj`).
With `--emit-geompy-normals`: `weighted_alpha_graph_geompy_normals.json`.

`weighted_alpha_graph.json` node census for the reference case:
`p0=54, p1=357, p2=679, p3=331, p2_topology_invalid=0` (backend `mixed_periodic_image_aware_core`).
These are **intermediate** — the skill keeps none of them in the user output directory (IP-minimal:
OBJ meshes/hierarchy expose engine internals and are discarded; only the extracted site artifacts
are returned).

## Failure modes

Nonzero exit / no `weighted_alpha_graph.json` / non-finite coordinates / `--input-sha256` mismatch
/ empty accepted-candidate set ⇒ engine or wrapper failure; the wrapper treats these as fail-closed.

## Reference invocation (recovered)

```
weighted_alpha_complex.exe \
  -f prepared_input/slab.POSCAR \
  -a 1.0 --pbc 1,1,0 \
  --voro-construction-mode pbc_masked_image_aware \
  --radius-file UFF.rad \
  --precursor-radius 1.52 \
  --placement-gap 0.1 --placement-step 0.0125 --placement-max-distance 8.0 \
  --emit-geompy-normals
```

Recovered case semantics (`ytk_agent_test_slab_universal_contact_NO3_radius1p52_pbc110_openmax_step0p0125`):

| Token | Meaning |
|---|---|
| slab input | `prepared_input/slab.POSCAR` (Cu/Ni/Ru/Co multi-metal slab, z-vacuum) |
| `NO3` | adsorbate label for naming/downstream pre-DFT POSCARs; engine consumes only its **radius** |
| `radius 1.52` | universal contact-anchor radius (Å) → `--precursor-radius` (legacy `-a`) |
| `pbc110` | periodic a,b; open c |
| `openmax` | vacuum/open side = +max side of the open axis (`--open-axis-side open-max`, skill-side) |
| `step 0.0125` | placement ray-scan step (Å) |
| site kinds | `P0→top`, `P1→bridge`, `P2→hollow` |
| ranking | per-kind by `min_clearance`; top-N (N=5) shown in `_{N}each.html` |
| `5each` | 5 sites per kind rendered in the 3D report (full set stays in json/csv/xyz) |
| result | `top=5, bridge=15, hollow=12, total=32`; min clearance ≈ 0.10005 Å; all ≥ gap 0.1 Å |

Note: `--open-axis-side`, per-kind selection, dedup, CSV/XYZ/HTML emission, and the
`regular_p1_p2_with_p0_top_exception_v1` acceptance policy are **wrapper-side** post-processing of
`weighted_alpha_graph.json`; the engine itself only builds the graph.
