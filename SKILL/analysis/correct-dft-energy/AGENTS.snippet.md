## Electrocatalysis energy-correction policy

- Use `$assemble-oer-energy-corrections` before publishing or revising a
  four-step AEM OER free-energy diagram, limiting potential, or thermodynamic
  overpotential.
- Use `$assemble-no3rr-energy-corrections` before publishing or revising a
  nitrate-to-NH3 free-energy diagram that uses HNO3/NO3- reference corrections.
- Never insert 4.92 eV or 1.12 eV without recording temperature, standard state,
  source, and evidence label.
- Never apply an HNO3 correction to all NOx species.
- Never rank a model that fails reaction closure or endpoint evidence gating.
- Keep gas-phase/molecular, phase-transfer, solvation, standard-state, and CHE
  terms separate so the report can audit double counting.
