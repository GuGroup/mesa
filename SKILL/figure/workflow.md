# Scientific Figures

Use the supplied data and structures with the matching figure skill.
`render-adsorbate-structure-grid` renders existing structures.
`plot-energy-diagram`, `plot-sabatier-volcano`, and `plot-dos` plot compatible
data. `create-nature-figure` can arrange existing panels.

Use accurate labels and units. Describe limitations relevant to interpreting
the figure and keep the data or structure paths available for reference.
Export in the requested format.
