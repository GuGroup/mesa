# Using MESA Skills

Run `initialize-mesa` to set up the repository and its tool runtimes. Start a
study from the user's request and supplied inputs. Use the requested calculation
backend and execution limits. Ask for essential inputs that are missing.

Read the relevant domain guide and the skill instructions before using a tool.
Give each tool the input files and settings it needs. Save outputs under the
user's requested directory or `project/<project_name>/`.

Write research outputs in English. Report the results, limitations, and failed
or incomplete calculations. Use the actual output files when writing a report
or manuscript.
